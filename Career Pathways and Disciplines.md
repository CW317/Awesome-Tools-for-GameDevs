# Game Development Career Pathways
## Systems Designer
Creates software systems that power a video game, assemble the technical resources that the game requires and any custom software that needs to be scripted for the game. 

## Level Designer
Focuses on the creation and practical implementation of levels, environment, stories, and quests wile considering flow, pace, and space.

## Game Programmer
Develops the software to create video games.

## Gameplay Engineer
Optimize and fix user interfaces, player notifications, gameplay mechanics, and game upgrades.

## Game Artist
Works on all visual elements required to put a game together such as characters, objects, textures, assets, environment, and props.

# Game Programming Disciplines
## Game Engine and System Programming
Building or extending core frameworks, memory management, and performance optimization.
Job Titles: Gameplay Programmer, Gameplay Engineer
Requires Skills:  Fluency in industry-standard software frameworks like Unreal Engine and Unity is required to manage assets, physics, and rendering loops.
## Gameplay Programming
Implementing rules, player mechanics, interactions, and game loops.
Job Titles: Engine Programmer, Engine Architect, Core Systems Programmer
Requires Skills: Mastery of foundational languages is essential, specifically C++ for high-performance and AAA engines, and C# for working within platforms like Unity.
## Graphics and Rendering
Writing shaders, managing lighting, geometry, and working with graphics APIs
Job Titles: AI Programmer, AI Engineer
Requires Skills:  Knowledge of low-level graphics APIs (like DirectX or OpenGL), shaders, lighting pipelines, and frame-rate optimization.
## Physics and Collision
Simulating realistic or stylized movement, gravity, and object reactions within the game world.
Job Titles: Physics Programmer
Requires Skills: Technical discipline in math, logic, and software engineering skills.
## Artificial Intelligence
Programming NPC behavior, pathfinding, and decision-making.
Job Titles: Network Programmer, Online Software Engineer
Requires Skills: Coding behavior trees, state machines, and procedural content generation for NPCs.
## Networking
Managing data synchronization, latency reduction, and client-server communication for multiplayer games.
Job Titles: Tools Programmer, Pipeline Tools Programmer
Requires Skills: Understanding client-server architecture, latency mitigation, TCP/UDP protocols, and netcode synchronization.
## UI and Input Processing
Creating responsive heads-up displays (HUDs) and mapping hardware inputs from keyboards, mice, or gamepads.
Job Titles: UI Programmer, UI/UX Engineer
Requires Skills: Understanding on how players interact with a game and how the game displays information back to them.
