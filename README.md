# Awesome-Tools-for-GameDevs
This is for a college assignment where I list 10 tools for game development.
These are in no particular order.

1. Unity Asset Store
https://assetstore.unity.com/
No need to reinvent the wheel, instead of making something from scratch you can check if it exists on the store page and use it instead of making the same thing from scratch.

2. Fantasy Name Generators
https://www.fantasynamegenerators.com/
Making names can be hard, this website has over 1700 name generators along with a few other generators, guides, and tools for use.
  2.5. Roll for Fantasy
  https://rollforfantasy.com/
  This is mainly for TTRPGs, but some of the tools could be helpful for game development

3. Hero Forge
https://www.heroforge.com/
Mainly for making miniatures for TTRPGs, it can be useful to make a rough idea of what a character looks like.
   3.5.
   https://titancraft.com/
   Similar to Hero Forge, but better for making more complex models as it lack restrictions some restrictions Hero Forge has.

4. MS Paint
https://apps.microsoft.com/detail/9pcfs5b6t72h?hl=en-US&gl=US
For when you need to make a placeholder for a 2D game, but don't care about quality. (Toby Fox uses MS paint for placeholders, you can too)

5. Dragon Map Maker
https://store.steampowered.com/app/1906050/Dragon_Map_Maker/
A map tool meant for TTRPGs (I am starting to notice a pattern here). For when you want to make a high quality map of a location.

6. Google (or any search engine really)
https://www.google.com/
This might be cheap to put on the list, but don't reinvent the wheel. Before doing something very complicated, check if someone has done the same thing but simpler. (Just make sure to give credit where credit is due)

8. Blockbench
https://blockbench.net/
While it is meant for Minecraft, it can be used for making pixilated models.

9. Minecraft
https://www.minecraft.net/en-us/store/minecraft-deluxe-collection-pc?OCID=cmmx0j7bkem_SEM_GA_MinecraftAcquisitionUSTraffic_Branded_Minecraft-Creative4-GBL&gad_source=1&gad_campaignid=24015787906&gbraid=0AAAAAC-2-qBvyvUbjyvwJ4bCWNFovIGx3&gclid=Cj0KCQjw5P7UBhDaARIsAOSlS1P59skTTd9Zwz5PlHwiqZfdJ5eaEOgyq8jBAjrNK_2yHGmTy4SSdn8aArtOEALw_wcB&tabs=%7B%22details%22%3A0%7D
Useful for making a rough idea for how you want something to look before committing to making/commissioning a model.

10. Planet Architect
https://store.steampowered.com/app/4300750/Planet_Architect/
As of writing this it isn't out yet, but you can use it to generate entire planets that use the properties that shapped Earth such as tectonic plates, temperatures, erosion, and more.
  10.5. Terra Firma 2
  https://store.steampowered.com/app/3422270/Terra_Firma_2/
  You can use it to simulate realistic terrain on a smaller scale. (Plus it is currently out)
